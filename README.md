# Domus Frontend

Base frontend de `Domus` construida con el mismo stack principal de `Atleta`:

- Ionic 8
- Angular 20
- Capacitor 8
- TypeScript
- Playwright para E2E

## Scripts

- `npm install`
- `npm start`
- `npm run build`
- `npm run test`
- `npm run lint`
- `npm run e2e`

## Notas

- La configuración inicial usa `storagePrefix: domus`.
- El backend esperado por defecto es `http://localhost:8080/api/v1`.
