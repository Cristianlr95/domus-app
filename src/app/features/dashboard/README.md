# Dashboard Feature

## Proposito
Vista principal para usuarios autenticados. Presenta accesos y resumenes de operacion segun permisos.

## Estado
Implementado con alcance parcial.

## Alcance actual
- Entrada posterior al login.
- Tarjetas y accesos a modulos disponibles.
- Visualizacion condicionada por permisos.

## Brechas conocidas
- Algunas tarjetas anticipan modulos que aun no estan implementados.
- Falta consolidar un shell autenticado compartido para navegacion y acciones globales.
